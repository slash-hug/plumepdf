# PlumePDF Cookbook

One task per file; every snippet is embedded from a compiling, CI-run test in `tests/PlumePdf.CookbookTests/` (via MarkdownSnippets — docs fail CI if they drift from source), and each recipe's expected output is its Verify snapshot. To prove your own usage: run `dotnet test PlumePdf.sln --filter CookbookTests` and diff `.received` vs `.verified`.
